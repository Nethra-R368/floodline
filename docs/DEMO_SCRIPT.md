# Demo video script (about 2:50, limit 3:00)

Speak normally, like you are showing a friend. Record at desktop size (Win + Alt + R or OBS). Before recording: add your Gemini key in Settings, press Reset, set speed to "fast".

| Time | On screen | Say |
|---|---|---|
| 0:00 | A news photo or headline from the 2023 or 2025 Chennai floods | "When Chennai floods, phone lines go down and people ask for rescue on WhatsApp." |
| 0:10 | A long WhatsApp-style list of requests | "Volunteer groups read these by hand. The same family gets posted ten times, two boats go to one house, and some requests just scroll away." |
| 0:22 | FloodLine, practice board | "FloodLine is a shared list for that. This is a practice night; all the names and numbers are made up." |
| 0:30 | Press Start the night | "Messages come in, in Tamil, English and Tanglish." |
| 0:40 | Requests appearing, map pins, "repeat messages merged" | "Each one is read straight away, even offline, and messages about the same household are grouped." |
| 0:55 | Open the top request; show the points table | "The most urgent are at the top, and you can see exactly why: pregnant, neck-deep water, how long they've waited." |
| 1:08 | Scroll to the grouped messages | "These three messages from different relatives are one family." |
| 1:15 | A "No one has taken this" row | "If nobody takes a request in 45 minutes, it's marked." |
| 1:22 | A "Family says they are safe" row, then the copy-reply | "If a later message says they're safe, or people keep forwarding it after the rescue, it's marked too, with a reply to stop the forwarding." |
| 1:35 | Two windows side by side; take a request in one | "When I take a request, every other volunteer sees it." |
| 1:45 | Switch to the live board, Load example messages, Add to board | "These are written like real messages: landmarks, Tamil, typos." |
| 1:55 | After Gemini: the Phoenix mall request now says Velachery | "Gemini re-reads them — 'near Phoenix mall' is Velachery. But anything it says that isn't in the message isn't used." |
| 2:10 | Results page, Run 20 different nights | "I can't test this in a real flood, so I simulated one: same boats, twenty nights. Households never reached: about 27 down to 1. Trips to families already rescued: 27 down to almost none." |
| 2:30 | Point at the worse rows | "It's not better at everything: lower-risk families wait a little longer, because critical ones go first. All of that is shown." |
| 2:40 | About page, helpline strip | "It's open source, it always shows the official helplines, and it's ready to try with a volunteer group this monsoon. Thanks." |
