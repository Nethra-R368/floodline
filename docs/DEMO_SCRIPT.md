# Demo video script (about 2:50, limit 3:00)

Record at desktop size with Win + Alt + R or OBS. Before recording: ⚙️ add your Gemini key, press ↺ Reset, set speed to 12 min/sec.

| Time | Screen | Say |
|---|---|---|
| 0:00 | A news photo/headline of Chennai floods (Michaung 2023 or Ditwah 2025) | "Every monsoon Chennai floods. Phone lines fail and rescue requests move to WhatsApp." |
| 0:10 | A long, messy WhatsApp-style list of SOS messages | "Volunteers read these by hand. The same family gets posted ten times, boats go twice to one house, and some requests just scroll away." |
| 0:22 | FloodLine board | "FloodLine turns that flood of messages into one shared rescue board, so nobody gets forgotten." |
| 0:28 | Press ▶ Play the night | "This is a simulated flood night: 270 messages in English, Tamil and Tanglish." |
| 0:35 | Cases appearing, pins on the map, "Repeats merged" counter | "Every message is read instantly, even offline. Repeats are merged: 230 requests become 110 households." |
| 0:50 | Click the #1 case; scroll the "Why it is ranked here" bars | "The most urgent are on top, with reasons a volunteer can check: pregnant, neck-deep water, waiting time." |
| 1:05 | Show merged reports + "same phone number" | "These four messages from different relatives are one family." |
| 1:12 | Point at a red NO ONE ON IT flag | "If no one takes a case in 45 minutes it turns red." |
| 1:18 | A case with SAYS SAFE NOW / RE-SHARED; show the copy-reply | "When a family says they're safe, or people keep sharing after a rescue, FloodLine flags it and gives a reply to stop the sharing." |
| 1:30 | Open a second window side by side; claim a case in one | "Volunteers work as a team: when I take a case, everyone sees it instantly." |
| 1:42 | Switch to Live, click "Try messy examples", Add to board | "Real messages: landmarks, Tamil, typos. Rules read them instantly." |
| 1:52 | Wait for "Gemini checked them…", open the Phoenix mall case → now Velachery; show a 🛡 blocked detail if any | "Then Gemini re-reads them: 'near Phoenix mall' becomes Velachery. And every AI answer is checked against the message, so it can't invent a phone number." |
| 2:10 | Proof tab → Run 20 different nights | "Does it help? Same boats, same night, twenty times. Households never reached: 27 down to 1. Wasted boat trips: 27 down to almost zero. Critical cases waiting over three hours: halved." |
| 2:30 | Point at the worse rows + assumptions | "It's not magic: low-risk families wait a bit longer because critical ones go first, and every assumption is editable here." |
| 2:40 | Phone view (dark) | "Works on a phone, in the dark, with no server. Chennai will flood again this monsoon; this is ready for it. Thanks!" |
