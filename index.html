        Does it actually help? The proof.

        The same flood night is replayed twice with the same boats: once the way volunteer groups work today (read the chat in order, phone back, post in the boat group), once with FloodLine. FloodLine's real extractor and duplicate matcher run on every message. Every assumption is a setting below.

        🎯 How well does it read messy messages?

        Two test sets. Generated: every message of the simulated night, with known answers (easy: same phrasing families the rules know). Hard set: 30 hand-written, hand-labelled messages the rules were never tuned on: landmarks instead of area names, Tamil number words, typos, loose offers.

        Why FloodLine exists

        When Chennai floods, phone lines fail and rescue requests move to WhatsApp, X and Instagram. Volunteers read them by hand. The same family gets posted ten times by relatives, so boats go to one house twice while another request scrolls away unread. Nobody knows which requests were handled, so old messages keep being shared after the family is safe.

        FloodLine is one shared board that tracks every request until someone confirms a rescue.

        1. Read anything. Paste messages in English, Tamil or Tanglish. Rules extract area, phone, people, water level and who is vulnerable instantly and offline; Gemini then reads landmarks and loose phrasing, and every AI answer is checked against the original text so it can't invent a phone number or place.
        2. Merge repeats. Reports with the same phone or same street + door number become one case, and the merge reason is shown.
        3. Rank by urgency, with reasons. Pregnant, medical, babies, neck-deep water, waiting time. Every point is explained.
        4. Nobody gets forgotten. Unclaimed for 45 minutes turns red. Claimed with no update for 90 minutes asks for a check-in. A "we are safe" message or a repost after rescue is flagged, with a ready reply to stop the sharing.
        5. Works as a team. Every action is an event; volunteers' boards sync instantly (tabs on one device today, any device with a small backend next), and the full log can be exported for handover.

        Prototype. Locations are locality-level. Demo data is simulated (realistic but fictional names and numbers); no real person's data is used.

        🤖 AI reading (Google Gemini)

        Optional. Without a key FloodLine still works with rules, offline. With a key, Gemini re-reads each message to catch landmarks, Tamil numbers and loose phrasing; guardrails reject anything not in the message.

        📦 Handover

        Export the full event log (every message and action) to pass to the next shift or another device.
